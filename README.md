# API Dokumentasi Auth

## Deskripsi

API ini memungkinkan admin/relawan untuk mengelola data penerima bantuan dan mendistribusikan donasi dari Modul 2 ke penerima yang membutuhkan. Terdapat fitur untuk:

<ul>Manajemen Penerima
<li>Mendaftarkan penerima baru (nama, alamat, kriteria).</li>
<li>Melihat daftar penerima aktif atau per ID.</li>
<li>Memperbarui atau menonaktifkan data penerima (soft delete).</li>
</ul>
